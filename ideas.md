# $MWIF Design Direction

## Three stylistic approaches

### Approach 1 — Phosphor Terminal
A raw black-screen terminal experience with acid-green phosphor text, purple interrupt states, scanlines, and hand-authored command-line rhythm. It should feel like a meme coin discovered through a leaked executable.

Probability: 0.03

### Approach 2 — Concrete Sticker Wall
A photocopied street-poster treatment with torn paper edges, hard black ink, taped-up panels, and aggressively condensed type. It should feel physical, irreverent, and built for screenshots.

Probability: 0.07

### Approach 3 — Night Market Signal
A sparse nocturnal interface with luminous purple wayfinding, green signal markers, and a cinematic black field. It should feel like a private transmission rather than a polished financial product.

Probability: 0.02

## Selected approach: Phosphor Terminal

### Design Movement
Neo-brutalist terminal UI fused with late-90s hacker zines and internet meme culture.

### Core Principles
1. **Command-line honesty:** UI copy reads like system output, not corporate marketing.
2. **Hard contrast:** black, phosphor green, white, and Solana purple carry the entire hierarchy.
3. **Visible texture:** scanlines, grain, rules, and cursor behavior make the screen feel lived-in.
4. **Controlled chaos:** the composition is structured, but small glitches and falling F letters create viral energy.

### Color Philosophy
Black is the default void, green is the live signal, white is the human-readable truth, and purple is the interrupt: the moment the system becomes a meme. The palette is intentionally tight so every accent feels ownable and screenshot-ready.

### Layout Paradigm
A vertical command stream with a centered executable header, left-anchored section labels, staggered cards, and a full-width F tribute chamber. Sections should feel like modules in one running process rather than unrelated marketing blocks.

### Signature Elements
- Thin phosphor rules with tiny status labels.
- Terminal chrome: prompt markers, blinking caret, window dots, and monospace readouts.
- Purple F interrupt moments, including the large press button and falling letter cascade.

### Interaction Philosophy
Every interaction should feel like a command acknowledged by the machine. Buttons press inward, counters update instantly, and the F wall rewards repetition with a visible burst of signal.

### Animation
Use short, snappy transitions for controls. Let the hero copy type in line-by-line, let the caret blink, and let falling F letters enter from above then disappear quickly. Respect reduced motion by disabling the typewriter and particle fall while keeping state changes clear.

### Typography System
Use **JetBrains Mono** for all interface text, with 400 for system output, 600–700 for section titles, and uppercase tracking for labels. Use Courier New as a resilient fallback. Avoid any sans-serif UI font so the page remains visibly terminal-native.

### Brand Essence
A meme coin for people who press F, hold conviction, and build through the bear — without pretending this is a bank. Personality: **irreverent, loyal, volatile**.

### Brand Voice
Headlines sound like commands or status messages. CTAs are direct, self-aware, and slightly reckless.

- `PRESS F TO PAY RESPECTS`
- `execute conviction --force`

### Wordmark & Logo
Keep the uploaded hand-drawn MWIF logo as the central mark. Pair it with a small generated graffiti-terminal F symbol only as a supporting favicon / signal marker, never as a replacement.

### Signature Brand Color
**Phosphor Green `#00FF94`** — the unmistakable live-signal color of the $MWIF terminal.

## Style Decisions
- Use generated terminal textures as low-opacity atmosphere behind HTML content.
- Keep the logo image user-provided and visually dominant in the hero.
- Treat placeholder social / chart URLs as explicit `#` links until real destinations are available.

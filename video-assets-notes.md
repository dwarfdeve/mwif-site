# MWIF Video Asset Notes

The visual direction uses dark neon-night city photography and community/technology atmosphere to complement the Phosphor Terminal palette. The reference source reviewed is Unsplash’s “Neon night” photography search page: https://unsplash.com/s/photos/neon-night. Unsplash licensing should be checked for any specific downloaded photograph before public upload; no watermarked stock imagery should be used.

Project identity assets available for the edits include the MWIF logo, animated logo effect, FFF signature assets, and the existing click sound. The planned cuts are a 30-second 16:9 YouTube video and a 15-second 9:16 Short, using the same terminal command sequence and FFF call-to-action with responsive-safe framing.
